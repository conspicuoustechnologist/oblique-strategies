# Oblique Strategies

Brian Eno & Peter Schmidt's deck of creative unblocking prompts, rebuilt as a browser terminal.

113 strategies. Draw a card. Get unstuck. Session history. Reshuffles when exhausted.

---

## Usage

Open `index.html` in a browser — no build step, no dependencies.

## Deployment

Handled automatically by `conspicuoustechnologist/deploy.sh` — rsync pulls this directory into `static/warez/oblique/` on every deploy.
